# 报告转公众号

Windows 本机小工具：把券商研究报告的 Word 文档转成可直接粘贴进微信公众号编辑器的
HTML。单文件 EXE，双击即用，转换和预览都在本机完成。

## 下载

到 [Releases](https://github.com/wiwiwiwiwii/dwss-official-account/releases/latest)
下载 `报告转公众号.exe`，放在任意位置双击运行。页面上会列出该版本的 SHA256，可自行核对。

运行需要本机已安装并可正常打开的 Microsoft Word 桌面版（转换要用到它）。程序本身不需要
另装 Python 或任何库。

## 用法

1. 双击 EXE，浏览器会自动打开工作台页面（地址只监听 `127.0.0.1`，带随机令牌）。
2. 拖入或选择 Word 报告，选报告类型（默认「自动」逐份识别），点「生成微信文章」。
3. 转换完成后在结果页点「复制正文」，到公众号编辑器里粘贴；标题可在页面上直接改，
   「复制标题」只写纯文本。

也可以把 Word 文件直接拖到 EXE 图标上，按记忆中的设置直接开始转换。

几条约定：

- 提取框架看文档结构，标题类型看封面页眉措辞，两者分开判定。
- 正文框架默认省略文末的「XX三大财务预测表」区块（标题段、表格图与数据来源），
  可在界面上勾选「保留文末盈利预测三表」。
- 含正文的转换会做图表与文字自检，结果显示在正文框顶端的信息条里。
- 同批最多 30 份，单份最多 100 MB。

## 隐私与网络

文档只在本机处理，不上传任何云端服务。程序唯一的网络请求是启动时向 GitHub 查一次本项目
的最新 Release：只发版本号、不含任何文档内容，超时 3 秒，失败静默；有新版本时页面左上角
出现下载链接。用 `--no-update-check` 启动可关闭这次查询。程序不会自动替换自身。

## 从源码运行 / 构建

```powershell
python src/app.py
```

```powershell
pwsh -NoLogo -NoProfile -File src/build.ps1 -InstallDependencies
```

构建产物是 `release/报告转公众号.exe`，脚本会同时复制到仓库根目录并打印两处哈希。
构建依赖装在上级目录的 `.build-venv`，不改动系统 Python。

## 已知边界

- 依赖标准研报模板的控件与正文标题样式；换模板需人工核对提取范围。
- 源图本身模糊时转换无法恢复细节，发布前仍需核对公众号里的图表与排版。
- 没有代码签名，首次运行 Windows SmartScreen 可能提示，选择「仍要运行」即可。
